# Desafios DIO

Repositório criado para documentar minha jornada de aprendizado através dos cursos, desafios, laboratórios e projetos realizados na **DIO (Digital Innovation One)**.

O objetivo é registrar não apenas a conclusão das atividades, mas também os principais conceitos aprendidos, práticas realizadas e conhecimentos adquiridos ao longo dos estudos.

---

## Organização

Os conteúdos são organizados por formação, curso e etapa.

Cada diretório possui sua própria documentação, contendo, quando aplicável:

* Conceitos estudados;
* Objetivos da atividade;
* Práticas realizadas;
* Resultados obtidos;
* Principais aprendizados;
* Evidências visuais;
* Referências e materiais complementares.

---

## Objetivo

Utilizar os desafios e projetos como uma forma de:

* Consolidar conhecimentos através da prática;
* Documentar minha evolução técnica;
* Desenvolver boas práticas de documentação;
* Criar um histórico público dos meus estudos;
* Transformar conhecimentos teóricos em experiências práticas;
* Construir um portfólio técnico.

---

## Tecnologias e ferramentas

As tecnologias utilizadas variam de acordo com cada curso e projeto.

Entre elas:

* Microsoft Azure
* Linux
* Docker
* Git
* GitHub
* Markdown
* Azure CLI
* Terraform
* Cloud Computing
* Infraestrutura
* DevOps

A lista será atualizada conforme novos estudos e projetos forem adicionados.

---

##  Evolução

Este repositório está em constante evolução e será atualizado conforme novos cursos, desafios, laboratórios e projetos forem concluídos.

A ideia é transformar cada atividade em uma oportunidade para **aprender, praticar, documentar e evoluir tecnicamente**.
